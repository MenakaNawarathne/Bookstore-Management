# BookStoresBlazor - SEN5001 WRIT1 Alignment

## Assessment focus
Interactive Mobile Application Development for Online Bookstore (WRIT1).

## Demonstrated functionality
- Customer registration/login and role-aware navigation
- Browse, search, filter and sort books
- Book details, cart, checkout and order placement
- Customer order history and status tracking
- Store Staff order processing and inventory monitoring
- Administrator user/role, book, author, publisher and sales management
- REST API endpoints with Swagger documentation
- Server-side validation, stock validation and friendly error handling
- Responsive/mobile-friendly layout and touch targets
